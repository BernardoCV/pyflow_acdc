North Sea MTDC multi-period TEP example data for `pyf.cases["NS_MTDC_2025"]()`.

Grid topology CSVs, expandable-element table, investment-period series, and
hourly market/load time series (2023–2025).

Usage:

```python
import pyflow_acdc as pyf

grid, res = pyf.cases["NS_MTDC_2025"](years_data="23,24")
```
