Grid Creation¶

This module provides functions for creating and manipulating power system grids.

functions are found in pyflow_acdc.grid_creator

Core Grid Class¶

class Grid(S_base, nodes_AC=None, lines_AC=None, Converters=None, nodes_DC=None, lines_DC=None)¶

In-memory AC/DC power-system model.

Central container for all network elements (AC/DC nodes and lines, converters, generators, renewable sources, price zones, time series) and the derived electrical quantities (e.g. Ybus) consumed by the power-flow, OPF, planning and plotting layers. Usually built via the grid_creator / grid_modifications helpers rather than constructed directly.

Parameters:

  • S_base (float) – System power base in MVA.

  • nodes_AC (list, optional) – Initial element lists; default to empty and are normally populated via the add_* helpers.

  • lines_AC (list, optional) – Initial element lists; default to empty and are normally populated via the add_* helpers.

  • Converters (list, optional) – Initial element lists; default to empty and are normally populated via the add_* helpers.

  • nodes_DC (list, optional) – Initial element lists; default to empty and are normally populated via the add_* helpers.

  • lines_DC (list, optional) – Initial element lists; default to empty and are normally populated via the add_* helpers.

Creating a Grid¶

import pyflow_acdc as pyf
grid = pyf.Grid()

Create Grid From Data¶

A more detailed description of the function can be found in the CSV files for importing data page.

create_grid_from_data(S_base, AC_node_data=None, AC_line_data=None, DC_node_data=None, DC_line_data=None, Converter_data=None, data_in=DataInput.REAL)[source]¶

Create a new grid from component data tables.

Parameters:

  • S_base (float) – Base power in MVA.

  • AC_node_data (optional) – Component data as a pandas/geopandas DataFrame or a CSV path string.

  • AC_line_data (optional) – Component data as a pandas/geopandas DataFrame or a CSV path string.

  • DC_node_data (optional) – Component data as a pandas/geopandas DataFrame or a CSV path string.

  • DC_line_data (optional) – Component data as a pandas/geopandas DataFrame or a CSV path string.

  • Converter_data (optional) – Component data as a pandas/geopandas DataFrame or a CSV path string.

  • data_in (str, optional) – Input data format ('Real', 'pu' or 'Ohm').

Returns:

[grid, res] — the constructed Grid and its Results.

Return type:

list

Example

grid, results = pyf.create_grid_from_data(100, ac_nodes_df, ac_lines_df)

Create Grid From Matpower¶

create_grid_from_mat(matfile)[source]¶

Create a grid from a MATPOWER .mat case file.

Load your MATPOWER .m case in MATLAB and save the case struct as a .mat file, then pass its path here.

Parameters:

matfile (str) – Path to the .mat file (.mat suffix optional).

Returns:

[grid, res] — the constructed Grid and its Results.

Return type:

list

Example

Create Grid From Turbine Graph¶

create_grid_from_turbine_graph(array_graph, Data, S_base=100, cable_types=None, cable_database=None, cable_types_allowed=3, curtailment_allowed=0.05, max_turbines_per_string=None, LCoE=1, trenching_cost=1, MIP_time=None, name=None)[source]¶

Create a grid from a turbine array graph and metadata.

Intended for offshore wind-farm array studies: builds the grid (nodes, sizing lines, renewable sources) from a turbine connectivity graph and the associated turbine/cable data.

Parameters:

  • array_graph (networkx graph) – Turbine connectivity graph.

  • Data (object) – Turbine/site metadata.

  • S_base (float, optional) – Base power in MVA.

  • cable_types (optional) – Candidate cable types / database and the max number selectable per line.

  • cable_database (optional) – Candidate cable types / database and the max number selectable per line.

  • cable_types_allowed (optional) – Candidate cable types / database and the max number selectable per line.

  • curtailment_allowed (float, optional) – Allowed renewable curtailment fraction.

  • max_turbines_per_string (int or None, optional) – Cap on turbines per radial string.

  • LCoE (float, optional) – Cost weights used by the sizing problem.

  • trenching_cost (float, optional) – Cost weights used by the sizing problem.

  • MIP_time (float or None, optional) – Time limit for the MIP path solve.

  • name (str or None, optional) – Grid name.

Returns:

[grid, res] — the constructed Grid and its Results.

Return type:

list

Reset All Classes¶

initialize_pyflowacdc()[source]¶

Reset all element class counters and name registries.

Needed when constructing grids manually (e.g. after a fresh pip install) to clear class-level numbering/name state between grids. create_grid_from_data and create_grid_from_mat call this automatically.

Example

pyf.initialize_pyflowacdc()

Create Sub Grid¶

create_sub_grid(grid, Area=None, Area_name=None, polygon_coords=None)[source]¶

Create a sub-grid from a larger grid by area or polygon.

Can be built from Area objects, area names, or polygon coordinates.

Warning

Currently unidirectional: the original grid is left in an unusable state after the sub-grid is created.

Parameters:

  • grid (Grid) – Original grid.

  • Area (list, optional) – Area objects defining the sub-grid.

  • Area_name (list of str, optional) – Names of areas defining the sub-grid.

  • polygon_coords (optional) – Polygon coordinates defining the sub-grid boundary.

Returns:

[grid, res] — the sub-grid and its Results.

Return type:

list

Example

subgrid, results = pyf.create_sub_grid(grid, Area_name="Zone1")
