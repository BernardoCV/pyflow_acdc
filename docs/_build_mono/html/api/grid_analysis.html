Electrical Parameter Utilities¶

cable_parameters(S_base, R, L_mH, C_uF, G_uS, A_rating, kV_base, km, N_cables=1, f=50)[source]¶

Convert cable data to per-unit equivalent parameters and rating.

For DC cables (L_mH == 0) N_cables is forced to 1 and a 2-conductor MVA rating is used; otherwise a 3-phase (sqrt(3)) rating is used.

Parameters:

  • S_base (float) – System power base in MVA.

  • R (float) – Series resistance per km (ohm/km).

  • L_mH (float) – Per-km inductance (mH), capacitance (microF), and shunt conductance (microS).

  • C_uF (float) – Per-km inductance (mH), capacitance (microF), and shunt conductance (microS).

  • G_uS (float) – Per-km inductance (mH), capacitance (microF), and shunt conductance (microS).

  • A_rating (float) – Current rating in A.

  • kV_base (float) – Voltage base in kV.

  • km (float) – Cable length in km.

  • N_cables (int, optional) – Number of parallel cables (default 1).

  • f (float, optional) – System frequency in Hz (default 50).

Returns:

[Rpu, Xpu, Gpu, Bpu, MVA_rating] (per-unit parameters + MVA rating).

Return type:

list

converter_parameters(S_base, kV_base, T_R_Ohm, T_X_mH, PR_R_Ohm, PR_X_mH, Filter_uF, f=50)[source]¶

Convert converter transformer/reactor/filter data to per-unit values.

Parameters:

  • S_base (float) – System power base in MVA.

  • kV_base (float) – Voltage base in kV.

  • T_R_Ohm (float) – Transformer resistance (ohm) and inductance (mH).

  • T_X_mH (float) – Transformer resistance (ohm) and inductance (mH).

  • PR_R_Ohm (float) – Phase-reactor resistance (ohm) and inductance (mH).

  • PR_X_mH (float) – Phase-reactor resistance (ohm) and inductance (mH).

  • Filter_uF (float) – Filter capacitance in microfarad.

  • f (float, optional) – System frequency in Hz (default 50).

Returns:

[T_R_pu, T_X_pu, PR_R_pu, PR_X_pu, Filter_pu] in per unit.

Return type:

list

Grid State and Analysis¶

grid_state(grid)[source]¶

Return aggregate load and generation bounds for the current grid.

Parameters:

grid (Grid) – Network to summarise.

Returns:

(total_load, min_generation, max_generation) in per unit.

Return type:

tuple

analyse_grid(grid)[source]¶

Detect enabled grid features and store boolean flags on grid.

Sets ACmode, DCmode, TEP_AC, REC_AC, TAP_tf, CT_AC, CFC, CDC, GPR, rs_GPR, and act_gen. Called at the start of power-flow, OPF, and TEP entry points.

Parameters:

grid (Grid) – Network to analyse (mutated in place).

Returns:

(ACmode, DCmode, [TEP_AC, TAP_tf, REC_AC, CT_AC], [CFC, CDC], GPR).

Return type:

tuple

current_fuel_type_distribution(grid, output='df')[source]¶

Summarise installed capacity by generation type (Static TEP style).

Parameters:

  • grid (Grid) – Network whose generators and renewable sources are counted.

  • output (str, optional) – 'df' for a pandas.DataFrame, 'dict' for a nested dict.

Returns:

Rows per fuel/technology plus 'All' and system-load summary.

Return type:

pandas.DataFrame or dict
